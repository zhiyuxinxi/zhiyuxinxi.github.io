# 无文字装饰素材

来源：仓库 `design-inputs/botanical-tree-approved-direction.png.base64` 所存、用户认可的原始生成图。依用户允许的裁切提取范围，仅保留有意义的图标插画、中央光晕外缘与边角叶簇；不是页面截图切块。

- risk/time/emotion/space/commitment/planning/growth/money：裁取对应无文字图标区，以羽化透明边缘连接纸面。
- center-rim：仅外缘光晕，中央原图文字所在区域透明挖空，页面“我”为真实文字。
- corner-sage/corner-reed：无文字边角植物，只为装饰，不属于数据节点。

装饰的屏幕几何不参与命中区域。所有父节点、叶节点、分枝曲线及文字都由代码控制。素材约114KiB，透明WebP；原图不复制进发布页面目录。
