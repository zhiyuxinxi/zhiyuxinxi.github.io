# 知遇测评 V4 · 保留式优化与在线设计工作台

打开根目录 `index.html`：左侧完整树结构，右侧可交互原型。`standalone.html` 为单文件产品原型；工作台依赖同目录资源，需完整解压。推荐在线站点或 `python -m http.server 8000` 后浏览 http://localhost:8000。

## 保留与修补

以原始交接包 + V2流程可靠性 + V3信息密度为共同基线。八套原始主题独立恢复，四套历史候选单列；人物、主题、字号、密度与动态设置独立。恢复每日入口和16PF主线；已有任务优先；个人页不突出空计数；精确分类落点；旧数据预检复制；中文输入与跨窗口覆盖保护。

## 文件

- prototype/：完整可交互源码，沿用V2的状态/持久化与来源保护。
- handoff/：主题源、42项结构、88条原始要求、119项职责、551行旧动作映射和事件契约。
- review/：对抗裁决、优势保留表与实际代码差异。
- qa/：本轮实际测试输出、范围、失败修复记录及截图；历史通过数不算本轮验证。
- tools/：主题生成、单文件构建、HTTP发布门禁与发布打包工具。
- DESIGN.md / UX-CONTRACT.md：视觉和行为的共同基线。

本轮同一助手进行对抗评审，未调用多个独立AI代理。并行测试进程只代表程序性验证。

## 业务边界

3道题为交互示例，不计16PF分数。报告独立虚构，AI预写演示。真实题源、计分、常模、登录、支付、退款和跨端同步未接入。会员真实价格与配额未擅自补值。真机、软键盘、辅助技术和审美偏好需继续验证。

## 重建

`python tools/build_themes.py`：从主题源生成完整主题CSS和JS。
`python tools/build_standalone.py`：生成单文件产品原型。
`python qa/tests/test_v2.py`、`test_v3.py`、`test_v4.py`：依赖Python Playwright和Chromium。
`python tools/hosted_smoke.py .`：依赖已安装Playwright Chromium，使用真实本地HTTP来源运行发布门禁。

发布包仅包含设计原型和非敏感资料，不包含生产密钥或真实用户数据。
