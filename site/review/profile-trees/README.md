# 画像树方案对比（独立设计探索）

入口：`/review/profile-trees/`。不加载App与业务状态层，不读取或写入localStorage/sessionStorage，不替换现有画像页。

三方案共用关系模式的D1/D2/D3/D4/D5/D7/D8/D9八个维度与少量合成记录。A圆形固定方位与分支，B四个视觉星簇与柔曲线，C环绕花瓣与拓展轨道。B的分区仅为排布，不新增心理分类；C面积没有数据含义。8是本次比较数据的大小，不是所有画像的轴数。

顶部保留人格倾向、关系模式、个人画像；本轮只有关系模式绘制可操作比较树。另两组打开结构说明，明确人格倾向仍有16个因子，不以8维代替；个人画像取代“我的观察”仅为本独立示例名称。没有改变生产APP名称或逻辑。未来测评完整度另行设计，不把资料状态当分数。

节点用边框形状、文字和符号表达未探索/有记录/待确认；暗节点可点。主分支固定，聚焦时只显示四角度。返回总览恢复原位置。三个方案同步同一个分支和角度，方便公平比较；手机切换方案，桌面并排。

使用真实button、原生select与details。节点可Tab聚焦、方向键循环、Home/End跳转、Enter/Space打开；Escape返回总览。手机选择叶子后进入详情，返回时回图；文字索引等效。示例输入只在内存中，临时加入后可以重置或刷新清除。

主题颜色与主题目录来自既有themes-v4.css与handoff/themes-v4.json，复用原ambient.js持久画布与原人物/标志。对比页外框允许显示设置，生产APP主题入口不变。静态开关与系统prefers-reduced-motion均停止背景；图形不漂浮旋转。没有游戏资产、真实题目、测评计分、AI或交友功能。

本目录自身拥有布局和交互。共享主题、背景、图像均只读复用。没有部署步骤；发布前须经独立审阅协调。
