## 设计决定

首页仅问候、原人物、稳定 16PF 主任务、必要的续接和四入口。删除品牌工具条的真实模板，不能以隐藏所有 .topline 代替。子页返回与报告分享是任务操作。

复用 themes-v4 的 scene-gradient / paper / surface / ink / primary，无新增独立配色。全局固定装饰层呈现潮汐，文字、人物和操作不参与位移动画。首页显色较强，正文页用纸面叠色保障阅读。中文系统字体与既有层级延续；呼吸环收至150px圆形，避免圈比人物抢眼。

### 产品视角挑刺

1. 原首页小尝试会替换16PF主线，且12类入口抢注意力：已固定主标题/状态主按钮，只有已存在的小尝试才出现次级续接。
2. 把所有入口移到助理会稀释输入任务：已改为探索承接认识工具与生活整理；我的承接资料与设置，助理只保留情境起点。
3. 不能仅保留函数却丢掉入口：新增迁移入口真实点击测试，生活整理仍可不登录、不测评保存并保留原ID。
4. 不能移除所有 topline：仅删除品牌工具模板，真实子页返回、分享、收藏和额度功能保留。V1/V2备用首页模板也移除了旧品牌条。

### 视觉视角挑刺

1. 原局部310px渐变与平纸底割裂：改为共享全视口潮汐层。首页显色，长文与答题低透明度；八套主题源未变。
2. 原人物没有拉伸，问题来自环与光晕：人物仍174×176 contain，环固定150×150，光晕12–20px，正文和人物均不运动。
3. 看过本轮实际首页320/390、已有行动、深色、探索和助理截图；主次清楚，底部四导航可见，人物比例无变形。其余尺寸/状态由截图矩阵留证。未声称真机或完整WCAG认证。
4. 探索页仍有较多功能，但按五生活议题与折叠认识工具分组；这是为保留业务入口的取舍，不把次要卡片放回首页。
