# 独立树视口契约

仅内存合成示例，无登录、题库、计分、保存、上传、AI和云同步。外部演示框清楚标记示例身份，产品画布不反复堆免责声明。

单击主枝聚焦并展开叶；单击叶展示行内详情。关闭详情不改平移、倍率或所选叶。返回全图保留选中叶的文字上下文。每tab恢复各自视口。根和主枝世界坐标固定，resize只改变容器投影。

单指/鼠标拖动画布，双指缩放；移动超过7px抑制随后的误点击。滚轮按指针位置缩放。倍率限制0.7–3；平移有限边界；全图恢复1倍中心。加减按钮、Home全图、方向键平移构成非拖拽等效；文字索引提供所有主枝入口。tab键盘左右/Home/End切换，Escape收起详情。

关闭动画、切tab及新手势取消旧视口动画，避免晚到帧恢复旧状态。语义层级使用不同进入/退出阈值。主题和减少动态不重建背景，不写本人状态。

本页外观/详情/视口由tree.css/tree.js拥有；无通用表格、业务表单、CRUD、日期、远程异步写入、模态或权限操作能力。本页仅加载同源静态主题目录；目录失败保留默认研究配色和可用节点，播报失败说明。

## 独立复核修复

未选择分枝时，放大仍保留父节点，不进入“仅选中分枝”的筛选；语义层标题仍为主枝。所选分枝存在时才展示该分枝的叶层。全图和重置可恢复全部主枝。

重建分枝DOM后显式聚焦新建的对应主枝按钮；详情展开同样恢复主枝，返回全图与收起详情聚焦视口。Tab继续到叶节点，Enter/Space均可操作。

父节点记录状态从叶节点派生；部分叶有记录时播报“部分线索有记录”，不能播报为“未探索”，也不能将点亮推断为全部完成。颜色与文字采用同一派生依据。
