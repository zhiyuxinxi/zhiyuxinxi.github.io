# 双主色柔光候选：保留、裁决与评审边界

基线：zhiyuxinxi/zhiyuxinxi.github.io main `1f4094e4cdf7be7fe1e71966eec025eaeca4893c`。源为 site/；根目录由发布流程镜像，本候选不手改镜像、不部署。用户最新明确放弃历史版本考古，要求两主色约15%–85%面积变化、方向自然转变与完整UI适配。

- 单因子/每日打卡/简化版/模拟性格四子页及AI重置版说明不改业务；示例/待开放身份保持。
- 八套完整独立主题；用户原logo字节、知遇测评名称保持。主题唯一入口仍是我的→设置。
- 四主导航职责和顺序、资料引用、中文输入、焦点恢复、禁用/错误/按下状态保持。
- 原ID保存认识→可选小尝试→观察→原依据与版本追溯；写入失败/离线/跨窗冲突/删除导出范围保持。
- 背景位于重绘容器外，同实例同时间；答题隐藏暂停并续播，减少动态静态。

## 本轮裁决与视觉方案

唯一显著装饰是大面积双主色柔光。面积32秒起伏，方向53/79秒、曲率47/61秒独立缓变；像素场逐点混色而非旋转一块几何图形。无随机帧、波浪描边、图层整体缩放。手机比例重新取分位点，保留主色最小份额。

颜色由 themes-v4.json 所有：field-a/b定义主色，surface/control-surface/overlay-surface/nav-surface等定义染色材料，ink/muted/primary定义文字与强调。正文与输入保留稳定实底，非所有控件透明。系统中文字体保持，主标题承担层级，正文不参与动画。四套独立历史候选保持其既有配色，只补画布主色映射，不混入八套发行方向。

面积计量读取实际截图：内容隐藏时按RGB投影中点分为两种主色优势区域，另报告中间混色带与两侧核心区域；约16/84目标为边界留余量。它不把被卡片遮挡的区域说成可见背景，也不是主色的纯色像素占比。正常页面截图和原速录像是判断视觉的主要证据，数值不能证明审美成立。

## 产品视角挑刺

首页双主入口可能让用户误以为AI版已可用或与原版同等有效，因此保留明确“交互示例／待开放”标识和完整边界。未改任何真实模型、计分、账号、支付或画像服务。

全局染色不能削弱阅读：正文/输入/弹层采用不透明染色底面，报告章节独立安静表面，答题没有背景运动。主题/路由切换仍由原应用负责，画布不持有资料。

## 视觉视角挑刺

- 极端比例下少数主色会退至边缘；不能只看50/50好看的中间帧。分别审8/16/24秒完整页面。
- 避免“透明即高级”：底栏及卡片有自己的表面，输入层级靠稳定底面和边界，深色主题单独审。
- 曾发现淡说明文字在极端主色上不足，已提高muted对比并收暗琥珀亮端；需以最终像素报告为准。
- 暖色主题整体更浓、主按钮更深，这是有意摆脱白纸贴彩底的候选；是否适合用户仍需独立视觉review，不以自动通过替代。
- 保留原logo，包含其原白色底；未擅自抠图、改画或染色。与暗色助理的视觉衔接仍是评审关注点。
