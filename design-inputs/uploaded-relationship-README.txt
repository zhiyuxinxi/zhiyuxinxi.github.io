关系需求图谱 · 移动端交互页面
================================

文件
- index.html   页面本体（单文件，不需要安装任何依赖）
- compare.png  原图（左）与实现（右）的对比

怎么打开
- 电脑：直接双击 index.html，用 Chrome / Edge / Safari 打开。
- 手机：把 index.html 放到任意静态网站托管（或自己的服务器）上，用手机浏览器访问。
  临时预览：在电脑上进入这个文件夹运行
      python -m http.server 8000
  手机连同一个 Wi-Fi，访问 http://电脑的局域网IP:8000

交互
- 点分类标题 / 图标：整支点亮或熄灭，橙色光沿藤蔓从「我」流向节点
- 点单个条目：只点亮这一条
- 点「我」：回到汇总，已点亮的分支上冲出一串光点
- 下方卡片：查看汇总或当前分支详情，可逐条开关、全部点亮、重置

常改的地方（都在 index.html 的 <script> 里）
- BRANCHES：分类名称、描述、三个条目及其小字说明。
  改文字即可，坐标数字是按原图测量的，不用动；条目文字长度尽量与原来接近。
- INITIAL_LIT：默认点亮哪些分支 / 条目（目前与原图一致：情绪支持、自由空间）。

说明
- 字体：思源宋体（Noto Serif SC），从 fonts.googleapis.cn 按需加载（国内可访问），
  失败时退回 fonts.googleapis.com，再退回系统宋体。正式上线建议自托管字体文件。
- 网址后加 ?still 可跳过入场动画、直接显示静态画面，方便截图。
- 系统开启"减少动态效果"时会自动关闭动画。
- 卡片里的描述与小字说明是占位文案，可按需替换。
