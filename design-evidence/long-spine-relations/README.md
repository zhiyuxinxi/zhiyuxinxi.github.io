## 本次差距与修改

此前主枝仍像短辐条，四侧面统一扇形展开。现在关系图采用八套人工长S/C控制点，主节点位于继续生长的主干中部，四侧面从不同弧长处接出。全览隐藏所有下级与末端叶片，主节点点击直接放大；业务叶片才可打开说明，中间层禁用。其他三图仅同步交互规则，独立构图不改。

真正RGBA叶片由用户提供的资产分支解码，沿末端切线旋转，文字保持正向。取消无业务装饰叶。手机聚焦倍率225%，大于视口的世界画布可拖动，不强求每次看到全图。
