# 真实透明线条材质 · 关系模式阶段

运行：site/review/portrait-art-study/index.html。单枝：single-line-study.html。未发布。

连接线本体已替换为四张透明纹理的连续网格，旧SVG连接path数量为0。两张原画经中心化拉直和透明边缘处理，派生鼠尾草/暖杏粗细条带；原图与base64不进入部署目录。main分支、APP和已发布画像树未改。

本阶段8主枝使用各自人工锚点和控制柄，含时间纵向S、自由空间横向舒展、金钱及底部更大回弯。纹理不改变稳定连接关系。单枝、完整图和放大截图均来自真实浏览器。

验证：15交互状态、4拓扑、40匿名节点索引；缩放、拖动、CDP双指、语义展开、浮层/焦点恢复、Canvas连续性和减弱动态通过。最终8/7拓扑与缩略渲染路径采样无交叉、无扇区越界。8/12的概览、缩放和展开检查纹理网格外缘，无文字或无关热区碰撞。

透明背景：dynamic-background.gif记录真实Ambient渐变，非性能录像。16背景采样点中12点在记录期间改变，背景Canvas实例不变。线条画布约95.8%像素alpha=0。精确比较保留画布、只清空材质：排除1px浏览器合成抗锯齿边界后，156432个透明背景像素变化为0。原始alpha=0边界差异897像素、最大通道差17也保存在报告中，不隐去。目视未见白色矩形或黑色边框。

不足：粗线略显编织质感，暖色粗线偏棕，概览细线偏淡；不宣称审美认可。WebGL依赖，实体设备和上下文恢复未验；其他主题尚未逐一审美验收。静态审计9项外部JS按钮绑定提示仍在，实际动作已有浏览器回归。WebM录制因Playwright专用FFmpeg缺失未执行，改用真实截图序列GIF。
